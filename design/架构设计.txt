├─────────────────────────────────────────────────────────────────┤
│ 适配层（模型/格式适配）                                         │
│ - 模型提供者系统（Providers）：Gemini/OpenAI/Ollama 等模型适配    │
│ - 工厂模式（Factory）：模型实例化与配置解析                      │
│ - 注册器（Registry）：模型ID与提供者的映射解析                  │
├─────────────────────────────────────────────────────────────────┤
│ 核心层（提取逻辑）                                               │
│ - 文本分块（Chunking）：长文档分片与并行处理                    │
│ - 提示工程（Prompting）：Few-shot 示例构建与模板渲染            │
│ - 结构化约束（Schema）：输出格式/字段级约束定义                │
│ - 对齐解析（Resolver）：提取结果与原文位置精准映射              │
│ - 数据模型（Data）：提取结果/示例/对齐状态等核心数据结构        │
├─────────────────────────────────────────────────────────────────┤
│ 工具层（通用能力）                                               │
│ - IO 工具：结果保存（JSONL）/读取                              │
│ - 分词器（Tokenizer）：文本token化与字符位置映射                │
│ - 异常体系（Exceptions）：专属错误类型定义                      │
│ - 进度管理（Progress）：长文档处理进度跟踪                      │
│ - 兼容性层（_compat）：版本兼容适配                            │
